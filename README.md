## 标着 NVMe 却给 SATA，下单前怎么认

这不是个别现象。AkkoCloud 那篇推广文的标题写「美国 NVMe VPS」，正文里承认官方套餐页把 VPS 磁盘标注为 SSD，只有独立的独立服务器产品线明确采用 NVMe，还建议用户下单前跟商家确认当前机型的具体规格。也就是说，主打 NVMe 的文章和实际在卖的 VPS 之间，隔着一层需要自己问清楚的东西。

搬瓦工的例子更细。它的 NVMe 是分机房推进的：DC9 洛杉矶、CABC_6 和 CABC_1 温哥华、HK3/HK8 香港、SLA 企业机房已经用上 NVMe RAID-10，普通 KVM 的 Basic 系列仍然是 SATA SSD RAID-10，CN2 GIA-E 系列里 DC9 升级了、DC6 还没全面升级。同一个品牌、同一个套餐系列，机房不同，盘就不同。

下单前可以做的核验动作有这么几个：

- 产品页的存储字段写的是 NVMe 还是 SSD，这两个词在主机行业里不通用，写 SSD 就是 SATA。
- 看有没有「NVMe RAID-10」这类具体描述。只写「高速硬盘」「SSD 存储」「企业级存储」的，都要问。
- 确认到机房。同一品牌不同机房硬件批次不同，别拿 A 机房的测评去买 B 机房。
- 开一单工单问清楚，把回复留着。真出问题时这是唯一凭据。

## 哪些需求根本用不上 NVMe

搬瓦工那篇测评里给了个挺实在的判断：静态网站受 NVMe 影响有限，普通 SATA SSD 套餐完全够用，不必为 NVMe 多花钱。跑的是纯静态页、个人博客、展示站，磁盘一年也读不了几次，多付的溢价买不到体感。

值得为 NVMe 付钱的是这些场景：WordPress 带插件和数据库、自建 Git、Docker 里跑几个容器、编译项目、小型数据库查询。这些操作的共同点是大量随机读写，机械感和 SATA 瓶颈在这里最明显。

流量型业务看的是另一个维度。做下载、直播源、跨境传输，先确认套餐是单向还是双向计费，再看带宽端口是 20Mbps 还是 1Gbps。LightLayer 洛杉矶那条线的不限流量款带宽只给到 20–30Mbps，跑得动轻量业务，跑不动大流量分发。

## FAQ

**便宜的 NVMe VPS 是不是都超售？**

共享型 VPS 基本都存在资源超售，差别在超售程度和物理盘类型。能核验的判断依据是实测 IO 数据，不是商家写的「NVMe」三个字。LightLayer 2024 年那台 4G 档实测约 225MB/s，同一时期搬瓦工 DC9 的 NVMe 平均读写能到 1GB/s 左右。同样是 NVMe，实际表现可以差四倍。挑之前去找带 fio 数据的测评，比看配置表靠谱。

**SATA 和 NVMe 建站差多少？**

搬瓦工测评里引用的实测数据：NVMe 平均读写约 1GB/s，普通 SATA SSD 顺序读取约 500MB/s；导入一个 500MB 的数据库文件，从旧硬件的约 20 秒缩短到约 4 秒；换装 AMD EPYC 后 yabs.sh 单核约 1466 分、多核约 6455 分。纯静态页面感知不到这个差距，动态站和数据库能明显感觉到。

**续费会涨吗？**

Exabytes 的条款明写促销价仅限新注册，续费回原价。这一条在东南亚主机商里很常见。LightLayer 的续费政策官网没有单独说明，下单页会显示 recurring 金额，结账前看一眼那个数字，比看首期价有用。

**流量双向计费具体怎么算？**

双向计费是把进站和出站流量加在一起算进月度额度。标 800GB 双向，实际可用量取决于你的业务上下行比例，网站类通常出站远大于进站，视频和下载类更极端。同样标 800GB，单向计费和双向计费的可用空间能差一倍以上。

**年付一定比月付划算吗？**

单价上通常是的。Exabytes 新加坡那个 S$20.71/月的数字，是三年付周期折算出来的月均价，一次性要付三年。年付省钱的代价是锁定期，中途换商家剩余价值拿不回来。第一次试某家，月付跑一两个月再转年付更稳。
